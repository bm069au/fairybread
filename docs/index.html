📖 Fairybread User Guide & Operating Instructions

Always available offline inside the app via F1 or Help → 📖 User Guide.

1. Guided Setup Wizard & OpenRouter One-Key Hub

1. Open ⚙ Settings → Launch Setup Wizard… (runs automatically on first launch and can be re-run anytime to simplify your keys).
2. Choose your profile—Light Chat & Research, Assignments & Writing, Simple / Heavy Coding, or Give Me Everything.
3. Want one prepaid billing balance for almost every AI model? Enable the OpenRouter Hub, enter a single key, and pick a preset tier (Free / Balanced / Flagship). Direct provider keys (Gemini, OpenAI, DeepSeek, Groq, Claude, etc.) always keep top priority whenever entered.
4. Click each link in the tick-off checklist to create keys, paste them into the DPAPI-encrypted fields, and verify your readiness in seconds.

2. Chat Controls, Steer / Queue, Weather Radar Maps & Deepgram Flux Voice

• Steer / Queue Composer: While agents are responding, type your next instruction and press Enter to either steer the active turn or queue it next.
• Honest Status Chips: Slow providers timed out by quorum appear cleanly in amber as Cutoff or Timeout rather than misleading error labels.
• Live Weather Radar Maps: Ask for local or global weather to see live RainViewer precipitation radar tiles layered over CartoDB Dark Matter alongside hourly and 7-day forecasts.
• Hands-Free Voice (|||✨): Uses Deepgram Flux + 89 English voices (or system/provider TTS) with live soundwave level metering and barge-in control.

3. 3-Layer Live Cost Tickers & $0.00 Free-Agent Local Memory Recall

• Click the bottom spend bar anytime to open the Spend & Billing Dashboard showing per-provider cumulative spend since your last top-up, a 1-click Reset ticker per provider, per-image cost badges, and live ongoing Voice Mode spending.
• Memory Palace Fast-Recall ($0.00): High-confidence matches in your local SQLite FTS5 memory.db skip paid web searches and answer using free-tier agents for $0.00 (include "recheck with full council" anytime to force a fresh web sweep).
• Living Memory Summary: View or edit what all connected AIs remember about you and your projects in Shared Memory → View & Edit Summary.

4. 300-DPI Graphics Studio, MCP Bridge & Experimental Mode

• Image & Print Studio: Ask naturally for banners, thumbnails, cover graphics, or 8×10 in / A4 300-DPI artwork. Stamped with exact provider cost.
• Experimental Mode: Launch autonomous multi-agent sessions with isolated Experimental Memory and Agent Mail. In Public builds, core source code stays verified and immutable—share proposed ideas in the GitHub Community Forum for credit under About → Community Contributors.
• MCP Bridge: Connect Google Antigravity, Claude Desktop, or ChatGPT Desktop to drive Fairybread as a local worker council.

5. Custom .json Color Themes, Selective AES-256 Backups & 1-Click Updates

• Color Themes: Download any .json color palette from the Color Themes tab and load via View → 🎨 Theme → 📥 Import Custom Theme (.json)….
• Selective Backup & Restore: Export an AES-256-GCM encrypted .zip archive—and restore API keys, settings, or memory together or separately from Settings or the Setup Wizard.
• 1-Click Updates & Hot-Reboot: Notice a newer version banner in the top bar? Click download, choose Update only in the installer, and let Fairybread relaunch cleanly without touching your data.
